# Zomato Data Engineering Project

## About the Project
This project uses Zomato food delivery data to build a data pipeline and generate useful insights.

## Technologies Used
- Python
- Amazon S3
- Snowflake
- dbt
- Apache Airflow
- Streamlit
- OpenAI

## Project Workflow
1. Collect food delivery data from CSV files.
2. Store the data in Amazon S3.
3. Load and transform data using Snowflake and dbt.
4. Automate pipeline tasks using Apache Airflow.
5. Explore data insights and AI-powered features.

## Project Features
- Data processing and transformation
- Automated data pipeline
- Food delivery data analysis
- AI-powered review analysis
